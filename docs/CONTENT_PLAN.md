Все наброски видны в общей ленте и в соответствующем разделе страницы `/projects`.

## Где редактировать

- Разделы и их описания: `data/portfolioProjects.ts`.
- Статьи: `data/blog/*.mdx`; поле `project` связывает статью с разделом.
- `inProgress: true` показывает отметку «В разработке». После завершения заменить на `false`.
- `draft: true` полностью скрывает статью из публичной ленты; для публичных набросков оставлять `false`.
- При завершении наброска сохранить имя файла и URL, обновить `lastmod`, заменить рабочие заметки готовым материалом.
